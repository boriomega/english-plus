# English Plus

تطبيق أندرويد لتعليم الإنجليزية للناطقين بالعربية، بواجهة عربية RTL ومحتوى تعليمي مناسب.

## المزايا الحالية
- واجهة عربية مبنية بـ Kotlin و Jetpack Compose.
- مسار دروس متدرّج مع قفل الدروس التالية حتى إكمال السابق.
- كلمات إنجليزية مع ترجمتها العربية.
- نطق الكلمات عبر محرك تحويل النص إلى كلام في Android (يتطلب توفر صوت English US على الجهاز).
- ألوان أزرق وأحمر وأبيض.

## البناء
يتطلب JDK 17 و Android SDK و Gradle 8.9:
`gradle assembleDebug`

## الحالة
نسخة أولية قابلة للتطوير. حفظ التقدم الدائم والاختبارات التفاعلية والرسوم الأصلية وتحسين الصوت ما زالت ضمن الأعمال التالية.
