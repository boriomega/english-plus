# English Plus

تطبيق لتعليم الإنجليزية للناطقين بالعربية بمسار تدريجي ومحتوى يومي مناسب.

## نسخة الويب التجريبية (Mobile-first)
افتح مجلد `web/` أو استضف محتوياته على GitHub Pages أو أي استضافة ملفات ثابتة:
- تصميم متجاوب للهاتف مع أزرار كبيرة مستديرة وتأثير ضغط.
- مؤثرات صوتية متنوعة عبر Web Audio API، مع نغمة ثلاثية قصيرة للإجابة الصحيحة.
- زر كتم الصوت وإعداد اختياري للانتقال التلقائي للسؤال التالي بعد 5 ثوانٍ.
- نطق الكلمات عبر SpeechSynthesis.
- رسوم SVG تعليمية للأشياء والفواكه والأشكال فقط؛ أزيلت رموز الأشخاص والوجوه والحيوانات.
- نوعا التمارين الأساسيان: اختيار من متعدد وترتيب الكلمات لتكوين جملة.
- هوية بنفسجية متوازنة مع خلفية رمادية فاتحة، دوائر دروس كبيرة، وتغذية راجعة خضراء للإجابة الصحيحة وحمراء للخطأ.
- نظام XP ومستويات، سلسلة أيام متتالية، قلوب تنقص عند الخطأ، وتدريب لاستعادة قلب.
- شارات إنجاز لأول درس، وخمس إجابات صحيحة متتالية، وسلسلة سبعة أيام.
- حفظ التقدم محلياً ودعم التخزين المؤقت للعمل دون اتصال بعد أول زيارة.

## نسخة Android
- Kotlin وJetpack Compose مع واجهة عربية.
- نطق الكلمات عبر Android TextToSpeech.
- مسار دروس متدرّج.

## الحالة
هذه نسخة أولية قيد التطوير وليست إصداراً نهائياً. يتضمن مسار A1 الآن 12 وحدة × 5 دروس (60 درساً) و240 مفردة/عبارة، مع مزامنة قائمة الدروس بين الويب وAndroid، وإضافة قاعدة لغوية ومثال مسموع لكل وحدة في الدروس. اختبار تحديد المستوى يعرض A1 إلى B2، لكن مسار A1 وحده مكتمل ومتاح حالياً؛ لذلك يوضّح التطبيق ذلك ولا يضع المتعلم في مسار غير منشور. الرسوم الحالية SVG بسيطة للأشياء والفواكه والأشكال، ولا تتضمن رسومات أشخاص أو وجوه أو حيوانات. ما زال يلزم توسيع مستويات CEFR، إضافة أنشطة قراءة وكتابة ومحادثة أعمق، اختبار التطبيق على أجهزة فعلية، وإعداد إصدار Android قابل للتثبيت قبل إعلان الإصدار النهائي.
