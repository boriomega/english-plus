# English Plus

An offline-first English-learning app for Arabic-speaking beginners.

## Product direction
- Free core lessons with optional paid features in the future.
- Arabic right-to-left interface and beginner-friendly English lessons.
- Core lessons designed to work offline; selected features may use the internet.
- Visual identity inspired by the American flag: navy, red, and white.
- Learning content and illustrations must respect the project's content guidelines.

## Initial milestone
Prepare the Android app foundation, lesson structure, and offline progress storage before adding larger content packs.

## Status
Project planning and repository setup.
