# English Plus

تطبيق لتعليم الإنجليزية للناطقين بالعربية، بمسار تدريجي ومحتوى يومي مناسب.

## نسخة الويب التجريبية (Mobile-first)
افتح مجلد `web/` لاستضافة النسخة عبر GitHub Pages أو أي استضافة ملفات ثابتة:
- تصميم متجاوب للهاتف مع أزرار كبيرة مستديرة وتأثير ضغط.
- مؤثرات صوتية مولّدة عبر Web Audio API: نقرة، إجابة صحيحة، إجابة خاطئة، واحتفال إكمال الدرس، مع زر كتم.
- نطق الكلمات عبر SpeechSynthesis باللغة الإنجليزية.
- مفردات مصوّرة برموز توضيحية، واختبارات تفاعلية مع فتح الدروس بالتسلسل.
- حفظ الدروس المكتملة والنقاط محلياً، ودعم التخزين المؤقت للعمل دون اتصال بعد أول زيارة.

## نسخة Android
- Kotlin وJetpack Compose مع واجهة عربية.
- نطق الكلمات عبر Android TextToSpeech.
- مسار دروس متدرّج.

## الحالة
هذه نسخة أولية قيد التطوير. يجب اختبارها على أجهزة فعلية، وتحسين الرسوم التعليمية، واستكمال حفظ التقدم والاختبارات في تطبيق Android قبل إعلان الإصدار النهائي.

## Android build
يتطلب JDK 17 وAndroid SDK وGradle 8.9:
`gradle assembleDebug`
